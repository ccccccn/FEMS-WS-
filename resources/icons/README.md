# 图标资源

这个目录用于存放应用程序的图标资源。你可以将以下图标添加到此目录：

- variable.png - 变量管理图标
- connection.png - 通讯配置图标
- monitor.png - 数据监控图标
- new.png - 新建项目图标
- open.png - 打开项目图标
- save.png - 保存项目图标
- exit.png - 退出图标
- add.png - 添加图标
- import.png - 导入图标
- export.png - 导出图标
- start.png - 启动图标
- stop.png - 停止图标
- about.png - 关于图标

## 推荐图标源

你可以从以下来源获取免费图标：

1. [Feather Icons](https://feathericons.com/) - 简洁现代的SVG图标
2. [Material Design Icons](https://materialdesignicons.com/) - Google的Material Design图标集
3. [Font Awesome](https://fontawesome.com/) - 流行的图标库
4. [Iconmonstr](https://iconmonstr.com/) - 简约风格的图标

## 使用方法

1. 下载合适的图标
2. 将图标保存到此目录（推荐使用PNG或SVG格式）
3. 确保图标名称与代码中引用的名称一致

应用程序将自动加载图标，如果图标不存在，将优雅地退回到不显示图标的状态。
