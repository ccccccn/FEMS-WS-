# 数据采集系统

这是一个支持多种工业协议的现代数据采集软件，支持分层管理：项目 → 设备 → 变量。

## 支持的协议

- S7 (西门子S7系列PLC)
- Modbus (TCP/RTU)
- CAN
- GOOSE

## 系统要求

- Python 3.7+
- PyQt5
- 协议特定的依赖库

## 安装

### 标准安装

```bash
# 克隆仓库
git clone <repository-url>
cd data-acquisition-system

# 安装依赖
python install_dependencies.py
```

### 使用模拟协议模式

如果您无法安装某些协议库（如snap7、pymodbus等），可以使用模拟协议模式启动系统：

```bash
python start_with_mock.py
```

模拟协议模式会生成随机数据，用于测试和演示系统功能，无需安装实际的协议库。

## 功能特点

### 项目管理

- 创建、编辑和删除项目
- 项目属性配置
- 项目导入/导出

### 设备管理

- 多种协议设备支持
- 设备连接配置
- 设备状态监控

### 变量管理

- 变量定义和配置
- 实时数据采集
- 数据记录和导出
- 阈值监控和报警

### 数据采集配置

系统支持灵活的数据采集配置：

1. **全局采集设置**
   - 全局更新频率：控制整个系统的基础采集周期
   - 全局数据记录：启用/禁用数据记录功能
   - 记录间隔：全局数据记录间隔

2. **变量级采集设置**
   - 采集频率：每个变量可以设置独立的采集频率，优先级高于全局设置
   - 存储频率：每个变量可以设置独立的存储频率
   - 存储开关：可以单独启用或禁用每个变量的存储功能

3. **存储设置**
   - 存储位置：可配置数据存储的目录路径
   - 存储格式：支持JSON和CSV格式

## 使用指南

### 启动应用

```bash
# 标准模式
python main.py

# 模拟协议模式
python start_with_mock.py
```

### 创建项目

1. 点击"新建项目"按钮
2. 输入项目名称和描述
3. 点击"确定"创建项目

### 添加设备

1. 选择一个项目
2. 点击"添加设备"按钮
3. 输入设备名称、选择协议类型
4. 配置设备连接参数
5. 点击"确定"添加设备

### 添加变量

1. 选择一个设备
2. 点击"添加变量"按钮
3. 输入变量名称、数据类型、地址等信息
4. 配置变量的采集和存储设置
5. 点击"确定"添加变量

### 配置数据采集

1. 在变量视图中切换到"采集设置"选项卡
2. 配置全局采集设置
3. 选择变量后，可配置变量特定的采集和存储设置

## 故障排除

### 协议库安装问题

如果无法安装某些协议库，可以使用模拟协议模式：

```bash
python start_with_mock.py
```

### 数据采集问题

如果数据采集不正常，请检查：

1. 设备连接配置是否正确
2. 变量地址是否正确
3. 网络连接是否正常
4. 协议库是否正确安装

## 开发者信息

### 项目结构

```
.
├── backend/               # 后端代码
│   ├── models/            # 数据模型
│   ├── protocols/         # 协议实现
│   └── services/          # 服务实现
├── frontend/              # 前端代码
│   ├── models/            # 前端数据模型
│   └── views/             # 界面视图
├── config/                # 配置文件
├── data/                  # 数据存储
├── logs/                  # 日志文件
├── projects/              # 项目文件
├── resources/             # 资源文件
├── main.py                # 主程序
├── install_dependencies.py # 依赖安装脚本
└── start_with_mock.py     # 模拟协议启动脚本
```

### 扩展协议

要添加新的协议支持，需要：

1. 在`backend/protocols/`目录下创建新的协议实现
2. 在`backend/protocols/__init__.py`中注册新协议
3. 在`install_dependencies.py`中添加新协议的依赖
4. 在`backend/protocols/mock/`目录下创建模拟实现
